Introduction

Getting to know FlowTrace

FlowTrace is a data acquisition and monitoring application for surface well testing. It reads the field sensors through a Modbus RTU device, shows the values live, saves every reading, calculates liquid and gas rates, raises alarms, and turns the data into graphs, tables and reports.

You canDetails
Read sensorsUp to 125 channels from one Modbus RTU device over COM / RS-485.
Log automaticallyEvery reading is saved to the Project database and a daily CSV file.
MeasureLiquid, oil and water rates and cumulatives, orifice gas rate (AGA-3), SF-DP, choke records.
WatchLive Stream, Monitoring View, trend graphs and High / Low alarms.
ReportGraph Studio PDFs, End-of-Well Report, calibration reports, P&ID sheets, challans, Excel exports.

Before the job

Activation and Projects

Activate FlowTrace on this computer

FlowTrace needs an activation key made for this computer. A key works only on the computer it was made for. No internet connection is needed.

  1. Start FlowTrace and name your first Project. The activation window opens and shows this computer's Machine Code (for example TNR5-P8J7-8PCN).
  2. Click Copy and send the Machine Code to the administrator by phone, WhatsApp or email.
  3. You receive a licence file (.lic) or a key. Copy the file to this computer and click Load License File..., or paste the key and click Activate.
Shown at the bottom leftMeaning
Licensed · N days leftFull licence, active.
Trial · N days leftTime-limited trial licence.
License expires in N daysFewer than 15 days left. Ask for a renewal key.
License expiredEnter a new key in Activation › Activate / Renew...
License cancelledThe administrator cancelled this computer's licence.
Note

When a licence ends, monitoring stops and all data logged so far stays saved. A new computer, a Windows reinstall or a new motherboard gives a new Machine Code and needs a new key.

One Project per well or job

A Project keeps everything for one job together: connection settings, channels, measurement columns, alarms, the database, CSV logs, reports and exports. Switching Project switches all of it.

To do thisUse
Start a new job with empty dataProject › New Project...
Go back to an earlier jobProject › Open Project...
Bring in a Project from another PC or a backupProject › Import Project...
Make a full copy of the current ProjectFile › Save Project As...
Tip

Name the Project after the well (for example Well-1). The name is shown on the toolbar and in the status bar, so everyone can see which job is being logged.

3

Hardware set-up

Device and channels

Connect to the Modbus device

  1. Plug the Modbus device (or USB-to-RS485 converter) into the computer and power it on.
  2. Click System Config in the menu bar, next to Help.
  3. On the Connection tab click Auto Detect, or pick the COM port yourself.
  4. Set Baudrate, Parity, Stop Bits, Byte Size, Timeout and Slave ID to exactly what the device uses.
  5. Optional: on the Storage tab change the Export Path and Database Path with Browse...
  6. Click OK.
SettingWhat to enter
PortThe COM port of the device or converter (see Windows Device Manager).
BaudrateCommunication speed, for example 9600.
ParityNone, Even or Odd. Must match the device.
Stop Bits / Byte SizeUsually 1 and 8.
Timeout (s)How long to wait for an answer before retrying.
Slave IDThe Modbus address of the device.
Check

A mismatch in Baudrate or Parity is the most common reason for no data. Read the settings from the device's label or manual.

Set up channels

Channels are the sensor values FlowTrace reads from the device. Open them with Channels on the toolbar or Measurement › Channels...

  1. Set Start Register (the first register to read) and Channel Count (1 to 125).
  2. Fill in each row as described in the table below.
  3. Use the ▲ / ▼ buttons on the right to change the channel order.
  4. Click OK. The names and units appear in every tab.
ColumnUse
Sensor NameA clear name, for example THP V5 or Sep temp.
UnitThe unit the value is shown in.
FormulaDouble-click (or click ƒx) to open the Formula Builder if the raw value needs converting. Leave Linear for a direct reading.
Multiplier (x) / Offset (+)Scale and shift the value for calibration. Example: a temperature sent in tenths uses multiplier 0.1.
VisibleUntick to hide a channel you don't need.
AlarmOpens the warning and alarm levels for that channel. See chapter 7.
Tip

Sensor re-wired to another channel during the job? Right-click that channel's heading in the Data Table and choose Sensor moved to another channel... Earlier readings stay on the old channel, new readings go to the new one.

4

During the job

Logging readings

Start and stop monitoring

  1. Set Log interval on the toolbar (1 to 300 seconds). This is how often a reading is saved, for example 60 s for one reading per minute.
  2. Optional: tick Average gaps to save the average of the readings taken during each interval instead of a single reading.
  3. Click the green Start Monitoring button (also in the RealTime menu). FlowTrace tries to connect up to 3 times and shows each attempt in the status.
  4. The status changes to Live when the device answers, and readings appear in the Live Stream.
  5. Click Stop Monitoring when the job is done. All logged data stays saved in the Project.
Note

Log interval and Average gaps can only be changed while monitoring is stopped. The Log interval is saved with the Project, so it is the same the next time the Project opens.

What happens while monitoring

  • Every Start creates a new logging session, so separate runs are never mixed together.
  • Each saved reading goes to the Project database and to a CSV file in the Live Log CSV folder of the export path, the moment it is read.
  • Live Stream, Data Table, Graphs and Monitoring View update automatically. Monitoring View refreshes every second.
  • Running totals (Cum Gas, Liquid / Oil / Water Cum) add the real time between readings. If logging stopped for a while, that gap is not counted as flow.
  • Alarms are checked on every logged reading (chapter 7).
Check

If the connection drops during a job, monitoring stops safely. Fix the cable or power and click Start Monitoring again. A new session starts and earlier data is kept.

Working with the data

Viewing and editing data

Live Stream

The Live Stream tab lists the latest readings, oldest at the top and newest at the bottom, one column per channel (Fig 1.1).

  • The table follows the newest reading. Scroll up to look at earlier rows; it stays there until you scroll back to the bottom.
  • Drag a column border to resize a column. Click Refresh to reload from the database.

Monitoring View

A compact window with the current value of every channel and measurement column, grouped like the sidebar. Put it on a second screen in the control cabin.

  1. Click the Monitoring View tab. It opens as its own window.
  2. Use the Group list to show one group, or All Inputs.
  3. Values refresh every second while monitoring. Size and position are remembered.

Data Table

The main grid: one row per saved reading, one column per channel and measurement column. A band above the headings groups the columns (Date / Time, Choke, Channels, and each measurement).

Find the rows you need

  1. Click Filter in the Data Table toolbar.
  2. Set the Start and End date / time. Optional: choose an Interval Filter (seconds, minutes or hours) to show one row per interval.
  3. Click Apply Filter. Reset returns to today's full day.

Headings, units and colours

  • Under every heading you can pick a unit label (psi, bar, °C, BPD, MMscfd...). It is a label only and never changes a value. To convert values, change the unit in Channels.
  • Green cells are values entered by the engineer (choke, BS&W, orifice data).
  • A cell coloured red or yellow is a reading on which an alarm fired (chapter 7).
  • Grid › Resize Columns to Fit sizes every column to its content.

Show or hide columns

The Table Configuration sidebar on the left controls which columns are shown in the Data Table, the Database tab and Excel exports.

  1. Type in the sidebar search box to find a column.
  2. Tick or untick a column. Ticking a group heading shows or hides the whole group.
  3. Use Show all / Hide all to change everything at once.
Note

Hiding a column never deletes its data. Tick it again to bring it back.

6

Calculations on every reading

Measurement columns

The Measurement menu adds ready-made measurement columns. They all work the same way: pick the sensor channel for each input (or a fixed value where offered), enter the meter or job parameters, and save. The new columns appear as their own group in the Data Table, sidebar, Monitoring View, graphs and Excel exports.

Liquid, Oil and Water Measurement

  1. Open Measurement › Liquid Measurement Rate... (or Oil / Water Measurement).
  2. Assign the measured-rate sensor and, where asked, the temperature and pressure sensors, or switch to Fixed and type a value.
  3. Enter BS&W, Shrinkage, Meter Factor and Combine Meter Factor.
  4. Enter the Starting Liquid, Water and Oil Cumulative if the job continues from earlier totals.
  5. Choose the Output Unit and click Calculate to preview with the latest reading.
  6. Click Save Config or Save as Column.
Liquid Rate = Measured Rate × Meter Factor Water Rate = Liquid Rate × BS&W / 100 Oil Rate = Liquid Rate × (1 − BS&W / 100) × Shrinkage × Combine Meter Factor

Orifice Gas Flow (AGA-3)

  1. Open Measurement › Orifice Gas Flow...
  2. Assign hw (differential pressure, inH₂O), Pf (flowing pressure, psig) and Tf (flowing temperature) channels. Tf can also be a fixed value. A Tf channel in °C is converted to °F automatically.
  3. Enter orifice bore (d), pipe internal diameter (D), gas specific gravity, base pressure and temperature, k and Fpv.
  4. Enter the Starting Cumulative Gas if the job continues from an earlier total.
  5. Choose the Output Unit and click Calculate. Flow rate, beta ratio, cumulative gas and every correction factor are shown.
  6. Click Save Config to add the Gas Rate and Cum Gas columns.
Q = C × √(hw × Pf) C = Fu × Fb × Fg × Y × Ftf × Fpv
  • Discharge coefficient: Reader-Harris / Gallagher (ISO 5167-2), with the expansion factor Y.
  • Z-factor: DAK correlation from gas gravity, at flowing and base conditions.
Check

Save Config recalculates the gas rate and cumulative gas of the whole stored history with the settings in the dialog. Check bore, gravity and the Tf channel before saving on a running job.

SF-DP Measurement

  1. Open Measurement › SF-DP Measurement...
  2. Choose the SF channel and the DP channel, or a fixed value for either.
  3. Optional: under Warnings & Alarms, switch on levels and set their limits (chapter 7).
  4. Click Save. Three columns are added: SF, DP and the SF − DP difference.
  5. Open the same menu item again to edit them.

Choke Manager

Record each choke change, so every reading shows the choke that was in service at that time.

  1. Open Measurement › Choke Manager...
  2. Click Add Row each time the choke is changed: date / time, choke size and choke type.
  3. Pick the Choke Size unit: 1/64 in or mm (mm = x / 64 × 25.4). Values are always stored in 1/64 in.
  4. Click OK. Every reading from that time onward shows that choke, until the next change.

Virtual columns

  1. In the Data Table click Add Virtual Column.
  2. Give the column a name and unit, and build the expression from your channels.
  3. Save. The column is calculated for every reading, old and new, and can be shown, hidden and reordered like any other column.
7

Safety

Alarms

Any Data Table column can have up to 5 alarm levels: channels, Gas Rate, Cum Gas, Liquid / Oil / Water, SF-DP and virtual columns. Each level is High (value at or above the limit) or Low (at or below), with its own name, limit, colour, popup and sound.

Set alarm levels

Open the level editor from any of these places:

  • Channel Configuration: the Alarm button on the channel's row.
  • Data Table: right-click the column heading › 🔔 Alarm...
  • SF-DP Measurement: the Warnings & Alarms box.
  1. Tick the box at the start of a row to switch the level on.
  2. Type the level name, choose High ≥ or Low ≤ and enter the limit.
  3. Click the colour box to pick the cell colour.
  4. Tick Popup and / or Sound, choose the sound (buzzer, chime...) and press ▶ to hear it.
  5. Use ＋ Add Level for more levels and ✕ to remove one.
  6. Set Repeat after Acknowledge: if the value is still past the limit after this time, the alarm comes back.
  7. Click OK.

When an alarm fires

  • A popup shows the level, value, limit and reading time, and the sound plays until someone responds.
  • Only the reading the alarm fired on is coloured in the Data Table (also in Export Data).
  • The status-bar alarm chip turns red while an alarm is not acknowledged.
  • Every event goes to the project's Alarm Log.csv.
  1. Press Mute to stop the sound (logged as SILENCED).
  2. Press Acknowledge once the situation is handled (logged as ACKNOWLEDGED).
Note

The popup stays open until acknowledged, even if the value has returned to normal, so a short spike is never missed. A small deadband stops a value hovering on the limit from alarming on every reading.

Colour key used in this example

High Alarm (red)High Warning (yellow)Low Pressure (blue)

The colours are your own choice per level. Pick colours that are easy to tell apart on the crew's screens.

Alarms window and Alarm Log

Open it from Alarms › Active Alarms & Alarm Log... or by clicking the status-bar alarm chip.

EventLogged when
ALARMA reading reaches a level's limit.
SILENCEDMute is pressed on the popup.
ACKNOWLEDGEDAcknowledge is pressed (or Acknowledge All).
RETURN TO NORMALThe value moves back past the limit.
  • Acknowledge All or Ctrl+Shift+A acknowledges every active alarm.
  • Filter the log with Show and the search box; Save Log As... exports it.
  • Alarms are checked on logged readings, so they follow the selected Log interval.

  2. Click Filter, set the date / time range and interval, then Apply Filter. Reset clears the filter.
  3. Optional: tick Multi-Track to give each channel its own band.

  • The Graph Only tab shows the same chart with nothing else on screen, ideal for a second monitor. It has the same profile strip and locks, Reset and Refresh Graph.
  • Plot › Full Screen Graph fills the whole screen. Press Esc to leave.

Graph Studio: PDF reports

  1. Template: pick a saved template or create a new one.
  2. Report heading: type the title, subtitle, footer and notes.
  3. Report header: type the well name. Click a dashed + logo box to add a logo (left = your company, right = client or partner); right-click a box to change or remove it.

  5. Display: adjust colours, axes and style.
  6. Click Export PDF and choose where to save. The PDF matches the preview exactly.
Tip

Save the look as a Template once and reuse it for every well. Templates keep the style, not the data. The report page always prints on white paper, whichever theme is used.

Paperwork

EOWR and Excel exports

EOWR Report (End of Well Report)

  1. Source Files: choose the content ZIP (PDFs, images, Office files), the Word format template (a default is provided) and the output folder.
  2. Logos (optional): Choose Logo... next to Company Logo (left of the page header) and Client Logo (right, and on the cover). Use Template Logo switches back.
  3. Section Mapping: click Analyze ZIP and check which section each file goes into.
  4. Report Details: fill in contract number, project, service company and client.
  5. Click Generate Report and wait for the progress bar. Then Open DOCX, Open PDF or Open Output Folder.
Note

Converting Word, Excel and PowerPoint files needs Microsoft Office on this computer. Otherwise convert them to PDF before putting them in the ZIP.

Export Data to Excel

  1. Filter the Data Table to the rows you want and choose the columns in the sidebar.
  2. Click Export Data (toolbar, File menu or Report menu) and choose where to save.

The workbook has the same grouped headers as the Data Table, alarm colours, and an image of the current graph.

Check

If the export fails, the target file is probably open in Excel. Close it and export again.

Add and arrange shapes

Connect equipment with lines

  1. Pick a line kind: straight, arrow, elbow or curved connector.
  2. Drag the two end handles onto the equipment you want to join.
  3. Drag the yellow handle to move the bend of an elbow or curved connector.

  3. The box now shows that row's value and updates when the table changes. Hover over it to see the link.

Images and extinguisher symbols

  • Image... places a picture (logo, photo, scanned sketch) that you can move and resize like a shape.
  • CO2 Extinguisher and DCP Extinguisher drop the standard symbols. Add a numbered Star or Text next to each to match the extinguisher list.

Field tools

Calculators

The Calculator, Flow Calculator, API Gravity and Average tabs are stand-alone tools. They never change your logged data.

Calculator tab

  1. Open the Calculator tab. The sidebar has four groups: Navigation, Conversions, Engineering Calcs and Reference.
  2. Click a page in the sidebar, or a card on the Main Menu.
  3. Conversions: type a value and pick its unit; every other unit is shown at once.
  4. Engineering calcs: fill in the Inputs (the unit is shown in each box) and click the blue Calculate button.
  5. The Result shows the answer. The green line under it repeats the formula with your numbers, so the calculation can be checked. The Formula Reference box explains each term.

Converts between psig, bar, kPa, atm, inH₂O, ftH₂O, inHg, mmHg and kg/cm².

Litres, US gallons, barrels, in³, ft³, cm³ and m³.

°F, °C, Kelvin and Rankine, with the conversion formulas.

Inches, feet, yards, miles, mm, cm, m and km.

bbl/day, bbl/min, gal/min, m³/day, m³/min and litre/min.

One rate shown in L/sec, gal/min, ft³/sec, ft³/min, bbl/hr and bbl/day at once.

Critical gas flow through a fixed choke: choke size (64ths), choke coefficient Cd, upstream pressure, wellhead temperature and gas gravity give the gas rate in Mscf/d, plus the choke in decimal inch and mm.

Multiplying factors from exa (10¹⁸) to femto (10⁻¹⁵).

Flow Calculator tab

  • Dry Gas Flow: line pressure, temperature, gas gravity, pipe inside diameter, flow velocity and compressibility give the flow at standard conditions (14.73 psia / 60 °F). Heating value is optional.
  • Orifice Meter: a quick orifice check on typed values, without touching the Orifice Gas Flow columns of the Project.
  • Click Calculate; Reset brings back the example values.

API Gravity tab

  1. Choose the Calculation Mode, for example Specific Gravity → API.
  2. Set the reference temperature (60 °F by default) and type the known value.
  3. Click Calculate. Specific gravity, API gravity and density are converted into each other.

Average tab

  1. Choose Date / time range or Last N Hours / Minutes ending now.
  2. Tick the channels.
  3. Fill in Well / Location, Prepared by and Description.
  4. Click Calculate Average. Each result shows its unit and the number of readings used.
  5. Export to Excel saves the results; WhatsApp Message sends them with the well, author and remarks.

When something is wrong

Troubleshooting and support

Cannot connect to the device

Message / symptomWhat to do
Could not open COM portCheck the cable and converter and the port number. Close any other program using the port (Modbus Poll, another FlowTrace window).
Access is deniedAnother program or a hidden duplicate COM port holds the port. Device Manager › View › Show Hidden Devices › Ports: uninstall grey or duplicate entries, reconnect and try again.
The device did not respondBaudrate, Parity, Stop Bits or Slave ID do not match the device. Correct them in System Config.
Connection drops during a jobMonitoring stops safely. Fix cable or power, then Start Monitoring. A new session starts; earlier data is kept.

Values look wrong or are missing

SymptomWhat to do
Wrong scaleCheck the channel's Unit, Formula, Multiplier and Offset in Channels.
Values in the wrong columnsCheck Start Register and Channel Count against the device's register map.
A column is missingIt may be hidden. Tick it in the sidebar.
Measurement column is emptyOpen its tool from the Measurement menu and check every input has a channel.
Rows missing in the Data TableReset the date / time filter. The table opens on today's date.
Gas rate unexpectedly low or highCheck the Tf channel: a channel in °C is converted to °F. Check bore, pipe ID and gas gravity.

Graphs, exports and activation

SymptomWhat to do
Graph is emptyThe time window has no data. Set Start / End to a period with readings, or click Reset.
Graph stays zoomed or a band looks squeezedAxis locks or a manual zoom are active. Use Graph Actions › Reset View.
Key "not valid for this computer"The key was made for another Machine Code. Send this computer's code and ask for a new key.
Start Monitoring is refusedThe licence has expired or was cancelled. Open Activation › Activate / Renew... and enter a new key.
